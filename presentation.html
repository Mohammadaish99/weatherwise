Euler Matrix 3D Transformation

Rotates the card on X and Y axes with perspective depth: perspective(1000px) rotateX(...) rotateY(...) translateZ(16px);

CASE STUDY: ADVANCED DEBUGGING

Overcoming the W3C CSS Perspective Stacking Trap

🔍 Deep Dive into CSS Transforms Module Level 1
1. The Reported Bug

When users clicked "Sign In", the modal dialog appeared to not open or was completely invisible on mobile and desktop screens.

2. The Root Cause Discovered in W3C Standards

The main container <div class="app"> had perspective: 1400px; for 3D depth. Per the W3C Transforms specification: "Any element with a transform, perspective, or filter property creates a containing block for positioned descendants, including position: fixed." Consequently, the modal was trapped inside the .app div thousands of pixels down the page, clipped off-screen!

3. The Architectural Solution

Relocated #authModal and #saveSpecialModal outside <div class="app"> directly under <body>. Configured position: fixed !important; inset: 0; z-index: 999999 !important; and appended cache-busting query strings (?v=5.0) for instant CDN updates.

EXPLANATION & DEFENSE GUIDE

College / Office Defense: Common Q&A Preparation

Q: Why choose Vanilla JavaScript over React, Next.js, or Vue?

A: Building in Vanilla JS demonstrates deep mastery of core browser APIs, the DOM, and graphics pipelines without relying on framework abstractions. Eliminating virtual DOM reconciliation overhead and 200KB+ dependencies ensures a smooth 60 FPS WebGL frame rate on mobile devices.

Q: How did you ensure Three.js does not drain mobile battery life?

A: The WebGL canvas renders transparently without expensive post-processing bloom shaders. We capped pixelRatio at 1.5, limited geometry segments to 28, and used only 240 particles, allowing hardware acceleration without GPU overheating.

Q: How do you handle API limits without paying for a backend proxy?

A: Open-Meteo allows free, unthrottled non-commercial public access. We implemented client-side caching, a 15-minute auto-refresh countdown, and localStorage persistence to prevent redundant network requests.

Q: How does user authentication persist without an external database?

A: We engineered an exception-shielded LocalStorage architecture with automated JSON serialization and fallback handlers for private browsing, storing credentials, unit preferences, and categorized favorite cities.
